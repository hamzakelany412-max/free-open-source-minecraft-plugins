Open-source Minecraft plugins for Paper servers, released under MIT. Source is available for anyone to use, modify, or contribute to.

SpawnerPlus — a spawner plugin with 6 main features 
1. mobs spawn directly above the spawner
2. you can multiply xp and mob drops by dropping an item in the gui
3. you can half the time it takes to spawn something by putting in a heavy core
4. antilag
5. you can add more than one spawn egg to increase spawn number (capped at 5)
6. everything is editable
MobForge — mob creator gui made for server owners who dont want to edit config files to create a simple mob

(both plugins are early access)
